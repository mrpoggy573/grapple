# grapple

## Run it
1. Put `server.js` and the `public` folder in your `school-io-game` folder.
2. In Command Prompt, run:

   npm install express socket.io

3. Start the server:

   node server.js

4. Open http://localhost:3000 in your browser.

Everyone who opens the same server address joins the same multiplayer world. To play with people on another computer, they must be able to reach your server address (for example, on the same network or through hosting/port forwarding).

## Controls
- A / D or left / right arrows: move
- W / Space / up arrow: jump
- Hold the left mouse button near an orange grapple point: grapple
- Reach the bottom edge of the Moon to float upward endlessly
- Click RESTART in the bottom-right corner to start climbing again

The shop sells colour changes for Reds collected from orange pickups. The server controls player movement and purchases.
